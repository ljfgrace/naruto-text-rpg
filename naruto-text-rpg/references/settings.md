## 一、世界背景

完全遵循岸本齐史《火影忍者》原著世界观、忍村格局、查克拉法则、时间线与人物逻辑。**原著怎么发生，故事就怎么推进——但你不是观众。** 随着实力与位置的提升，你有机会站进名场面里，凭选择和实力改写其中某些结果；一旦改写，后续世界会真实地记住这次改变并推演连锁反应。

这是一个忍者主宰的世界。五大国各拥一座忍者隐村——木叶（火）、砂隐（风）、雾隐（水）、岩隐（土）、云隐（雷）——以"影"为军事领袖；忍村之外，还有雨隐、草隐、汤隐等小村，以及佣兵、浪人、商队与小国。忍者以提炼自身体细胞能量与精神能量的**查克拉**施术：忍术、体术、幻术、封印术、医疗术、仙术；少数家族拥有**血继限界**，更有尾兽、仙人、六道之力等凡人不可企及的领域。

你不是鸣人，不是佐助，也不是第七班的人。你是一个带着家传四象忍术、通灵契约和一把旧刀的23岁浪迹忍者。故事元年春天，你走进木叶大门，随后被编入这个时代的核心战场——从波之国的大雾开始，一直走到辉夜降临的那一天。

## 二、原著力量体系（严格对标，不另起炉灶）

### 2.1 忍界实战层级顺位

下忍 → 中忍 → 特别上忍 → 上忍 → 精英上忍 → 影级 → 仙人/超影级 → 六道级

- 强弱看四样：**查克拉量、查克拉控制、战术心性、经验与情报**。
- 血继限界、尾兽之力、仙人模式（三大圣地）、六道传功属于原著人物的核心机缘；李建锋的六道级是**四象流自身修到极致的原创路径**，不抢占鸣佐任何一份机缘（见第4.5节）。

### 2.2 主要势力与纪年锚点

- 五大隐村：木叶（三代目猿飞日斩在任→纲手→卡卡西→鸣人）、砂隐（风影我爱罗）、雾隐（血雾→照美冥）、岩隐（大野木）、云隐（四代雷影艾、奇拉比）。
- 晓：佩恩（长门）表面首领，带土幕后操盘，收拢尾兽以行月之眼；音隐大蛇丸；妙木山/龙地洞/湿骨林；铁之国。
- 纪年：约13年前九尾之乱；约7年前宇智波灭族；故事元年春鸣人12岁毕业；两年半后疾风传（鸣人15岁）；第四次忍界大战鸣人17岁、**李建锋28岁**。

## 三、玩家身份

姓名：**李建锋**　年龄：23岁（故事元年）　性格：**开朗、自来熟、爱管闲事但分得清轻重**，笑起来像个走街串巷的货郎，越是难打的场面嘴越碎。

- 出身：**汤之国·汤隐里**（已降格为温泉观光町）。李氏一族曾是汤隐的**渡り调停忍**，家传**四象流忍术**、**文鳐鱼通灵契约**与名刀，世代经营中立护送与说和买卖，在各国忍村间都有薄面。族人或死或散，他是全套家传手艺的最后传人。
- 现状：独行佣兵忍者（无护额、无村籍），持猿飞日斩亲笔签发的**外部协力者契约**，故事元年春入木叶；因能力全面、口风紧、不属任何派系，很快被三代与卡卡西信任，**以协力忍者身份长期随第七班及其联合任务行动**。
- 他**不是穿越者**。玩家读过火影，李建锋没有——上帝视角指令按"主角缺乏信息渠道"处理。
- 私人钩子：十年前李家最后一支商队连人带货人间蒸发，货中有一样"会唱歌的东西"。原创伏笔，**不得挂靠任何原著名人、尾兽、通灵兽或六道设定**。

## 四、核心能力：四象流（水火土木，家族代代传承，非血继限界）

**家族理念：借天地四象之力，攻、探、控、愈一体；不追求单一毁灭爆发，讲究灵活切换属性应对战局。**

### 4.0 关于"木"与原著的兼容

四象流的"木"**不是千手血继木遁**（无需同时发动水土性质、无中生有造巨树），而是以阳遁生机之术操控土中**既有**的种子与根系；离开植被覆盖区域威力大减。S级的万木同春也只是把现有根系催到极致、时效有限，凋谢后土地恢复原状，永远变不成柱间的木遁。

### 4.1 忍刀：**「断潮」**（主武器）

李家世代相传的直刃忍刀，刀身长二尺二寸，暗青刀身有四色暗纹（火纹赤、水纹苍、土纹黄、木纹碧），以文鳐鳞片与查克拉钢反复锻打，**导查克拉效率极佳、四属性皆不排斥**。配装：刀背有凹槽可贴起爆符；另带短忍刀「问津」（怀刀/投掷两用）、注连捕绳「括」、苦无、手里剑、兵粮丸、收纳卷轴。

刀法为调停忍实战路数——**「四象刃」**：火附燎芒为切割灼烧之刃，水覆润流为卸力黏刀，土凝岩脊为重劈破甲，木缠根须为缴械锁刃。没有什么天才剑豪之名，只是一个打了十几年护送遭遇战的人，刀法干净、狠、不花哨。

### 4.2 四属性分工与术梯度

火主爆发；水主治疗＋软控；土主控场防御；木主探测束缚生机。每属性都有C～S的完整阶梯（B、A级只列名一句；**S级与禁术详述**）。

**火（爆发伤害）**
- C 火遁·燎芒：指尖/刀身放出细长高温火丝，单点灼烧切割，连中可引燃查克拉外衣，快速破防。
- B 火遁·燎丝网：火丝交织成网，封锁走廊与退路。
- A 火遁·燎原径：刀劈出扇形火线推进，焚尽伏兵与起爆陷阱。
- **S 火遁·朱雀燎天**：查克拉化作展翅火雀俯冲，触物爆为不扩散的白灼焰核，温度高到可短暂烧穿尾兽查克拉外衣、熔断秽土转生者的躯体（秽土者会复原，但能为封印班争取完整窗口）；全力一刀可劈开影级忍术对冲。耗蓝巨大。

**水（治疗＋软控）**
- C 水遁·润脉：清水查克拉覆伤止血、舒缓经脉、缓解查克拉疲惫，战场应急，可连救数人。
- C 水遁·缠汐：水流缠四肢，降敌移速与结印速度，地面湿滑克体术忍者。
- B 水遁·缠汐锁：水绳锁链化，缚关节、封结印。
- A 水遁·甘霖：小范围治愈之雨，轻伤瞬愈、重伤吊命。
- **S 水遁·沧溟倒悬**：双形态。攻形态——半空凝出倒悬水牢，高压水流如万刃绞杀，可困杀影级以下、压制尾兽化边缘；愈形态——大范围活水倾盆，配合文鳐引潮吐润可覆盖整个营地，只要还有一口气就能从死亡线上拉回来（**可救治"原著标准下的濒死者"，但对已死者无效、不能复活**）。

**土（控场防御）**
- C 土遁·层垣：多层土墙升地，挡攻、隆起困敌、拆石块砸人。
- B 土遁·层垣连环：土墙接连生成，阵地推进。
- A 土遁·万壑壁垒：包裹阵地的巨大土壳，硬接A级忍术轰炸。
- **S 土遁·岱岳镇渊**：召出小山般的土岳压镇或作壁，正面**硬接一发尾兽玉级轰击而不碎**（仅此一发级别的极限，之后土墙崩解）；亦可化作土龙巨掌拍按、镇封整片战场，是他能在影级战场上站住脚的底气。

**木（探测束缚生机）**
- C 木遁·根索探：细密树根蔓延区域，感知位置与查克拉流动，敌踏入即缠脚锁行。
- B 木遁·根索牢：根系编牢，困住中忍级小队。
- A 木遁·千根缚界：根枪与根网封锁街区，上忍亦难脱身。
- **S 木遁·万木同春**：将方圆数里内现有根系催为临时密林，万根齐发可缠绕影级对手数十息，林间队友持续恢复体力与查克拉（非治疗，是生机回补）；时效一到密林枯萎。非血继、不可移植、不可凭空造林。

**合**
- C 四象合·轮转阵：土筑边界、木布感知网、水牵制、火灼烧，阵内元素互济，敌持续被消耗、己方持续被疗伤；每场至多一次，怕大范围风遁。

### 4.3 禁术：**四象禁·太初判**（水火土木四属性）

李家卷轴最深处的禁术，又称"**四象归一**"。水火土木四股查克拉在经络中**同时逆行、归于一点**，强行模拟出五行运转之前"不分阴阳的初始之力"附着于断潮一刀——斩出的一线灰白刀光，**不按属性相消的规则走，可切开仙术查克拉、尾兽玉外壳乃至六道级防御**，是四象流理论上的极限。

- 代价：一刀之后全身查克拉彻底干涸、经络寸断般剧痛、濒死昏迷数日，须顶级医疗＋数月静养，**可完全恢复，不留永久损伤**（家族世代以药物与吐纳续接经络的成果）。
- 门槛：查克拉量与四属性控制未到影级圆满前强用，当场死亡——这是它被封进卷轴深处的原因。
- 定位：全剧前期与中期**不许使用**；随成长逐步具备条件后，它是四象流叩响六道之门的钥匙（见4.5）。

### 4.4 弱点（AI必须执行）

1. 高消耗：多属性同维持极易透支，轮转阵每场一次，S级术每场通常只放得起1～2个。
2. 风遁克制：B级以上大范围风遁（手鞠镰鼬、大蛇丸级风遁）可吹散轮转阵、压制火与细木。
3. 单属性正面不如各国专精忍者，强在切换与多功能。

### 4.5 成长路线（主角是成长性的，终点六道级）

四象流的深层设定：四象循环运转到极致，水火土木自洽为一个小周天，与文鳐的自然共生之力合流后，可**不借助六道仙人传功、不靠尾兽、不靠血继**，自行触摸"阴阳遁·万物自生"的领域——一条李家祖上有人窥见、却无人走到的野路子。**他的六道级是"人靠自己练到的六道级"，粗粝、短暂、消耗惊人，但层级为真。**

## 五、通灵兽：文鳐鱼（《山海经·西山经》）

> 状如鲤，鱼身鸟翼，苍文白首赤喙，常行西海，游东海，夜飞。

巨型锦鲤，背生宽大鸟翼，鳞片青红纹路，陆海空皆行。性格沉稳、不喜厮杀，长侦查辅助支援；主人陷入死斗才全力进攻，会在李建锋上头时用尾巴拍他后脑勺。

1. **水脉感知**：感知地下水、溪流、根系，与根索探互补（根索管地面，水脉管地下纵深），大范围索敌。
2. **引潮吐润**：喷温和活水，缠汐范围翻倍，并大幅增幅润脉/甘霖/沧溟倒悬的治疗量。
3. **振翼燃息**：高温气流把燎芒火丝由点扩成面，增幅朱雀燎天的覆盖。
4. **鳞土覆身**：落鳞化硬土，瞬筑矮墙补防、连环困敌。
5. **共生生机**：鳞粉催生草木，配合根索与万木同春速成林地。

契约规则：共享自然元素感知，主人施术时文鳐同步增幅（只加幅度与范围，不改性质、不跨级抬术）；每日全力同步约30分钟（随羁绊成长可延长）；非战场不得随意通灵巨兽；正面不敌万蛇、文太级。文鳐沟通自然的天赋，是4.5节成长终点不可或缺的另一半。

## 六、负荷体系（查克拉透支；无永久损伤）

以 **0～100 查克拉透支**计经络疲劳：

- C级每轮＋4～6；两属性同开每轮额外＋6，三属性＋12，四属性＋20；轮转阵启动＋45、维持每轮＋15、被风遁击破再＋20。
- B级＋15，A级＋30，**S级＋60**（每场通常只够1～2个）；**禁术·太初判：启动即满100并濒死昏迷，进入数月恢复期**（影级圆满前使用＝当场死亡，AI必须先预警）。
- 兵粮丸一次－20（每日2颗为限）；文鳐增幅耗它自己的同步额度；休息每小时－15，饱睡回满。
- ≥40切换变钝；≥70只能单属性、治疗减半；满100昏迷6～12小时。
- 一切透支伤病经休息医疗**完全恢复，无永久损伤、不折寿**。越往后成长，蓝条越长、恢复越快，但S级与禁术的代价始终真实。

## 八、原著时间线（随第七班深度同行；节点可凭实力与选择改写）
